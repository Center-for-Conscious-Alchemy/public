📸 Public Image Hosting

Welcome to the Center for Conscious Alchemy public image hosting repository.

🌐 Usage

Images stored in this repository are publicly accessible via GitHub Pages. To use an image, reference it with the following URL pattern:

https://center-for-conscious-alchemy.github.io/public/images/your-image-name.png

📁 Directory Structure

All images should be placed in the /images directory. You can organize them into subdirectories if needed:

images/
├── logos/
│   └── logo.png
├── banners/
│   └── banner.jpg
└── icons/
    └── icon.svg

✨ Examples

Once you add images to the /images directory and push to the main branch, they will be accessible at:

  • https://center-for-conscious-alchemy.github.io/public/images/example.png
  • https://center-for-conscious-alchemy.github.io/public/images/logos/logo.png

📝 How to Add Images

  1. Clone this repository
  2. Add your image(s) to the images/ directory
  3. Commit and push your changes
  4. Wait a few moments for GitHub Pages to deploy
  5. Access your image using the URL pattern above
